This is a documentation package for a Restaurant Management System (RMS) project for 3 members using C programming.

The project is based on a hypothetical restaurant "Golden Spoon Diner" covering inventory, orders, bookings, staff management, and financial analytics.

## 🛠️ Technology Stack

### Programming Language
- **C** (Standard C99 or later)

### Development Tools
- Any C compiler (GCC, MinGW, Clang)
- Text editor or IDE (VS Code, Code::Blocks, Dev-C++)
- Command-line/Terminal

### Concepts Used
✅ Loops (for, while)  
✅ Functions  
✅ Conditional statements  
✅ Arrays (1D and 2D)  
✅ Input/Output operations  
✅ Basic data types (int, float, char)

### Concepts NOT Used
❌ Enums  
❌ Structs/Classes  
❌ File I/O  
❌ External libraries  
❌ Pointers (kept minimal)  
❌ Dynamic memory allocation
