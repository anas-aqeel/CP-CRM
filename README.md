## 📖 Introduction

This is a **comprehensive documentation package** for a Restaurant Management System (RMS) project designed for a team of 3 members using **C programming language**.

The project is based on a hypothetical restaurant called **"Golden Spoon Diner"** and covers all essential restaurant operations including inventory, orders, bookings, staff management, and financial analytics.

**Note:** This is a **planning and documentation package** - the actual C code implementation is left for the students to develop based on these specifications.

## ✨ Features Overview

### 🔐 Admin Features
- **Inventory Management** - Track stock levels, add items, low stock alerts
- **Order Management** - View all orders, update status, track history
- **Booking Management** - Handle reservations, check availability
- **Staff Management** - Add staff, attendance, salary calculations
- **Financial Analytics** - Revenue, expenses, profit, ROI, tips

### 👤 Customer Features
- **View Menu** - Browse items by category with prices
- **Place Order** - Select items, add to cart, confirm order
- **Track Order** - Real-time order status tracking
- **Complete/Reject Order** - Finalize or cancel orders, add tips

### Programming Language
- **C** (Standard C99 or later)

### Development Tools
- Any C compiler (GCC, MinGW, Clang)
- Text editor or IDE (VS Code, Code::Blocks, Dev-C++)
- Command-line/Terminal

### Concepts Used
✅ Loops (for, while)  
✅ Functions  
✅ Conditional statements  
✅ Arrays (1D and 2D)  
✅ Input/Output operations  
✅ Basic data types (int, float, char)

### Concepts NOT Used
❌ Enums  
❌ Structs/Classes  
❌ File I/O  
❌ External libraries  
❌ Pointers (kept minimal)  
❌ Dynamic memory allocation
